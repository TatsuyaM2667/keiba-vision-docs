## 流れ

```text
Wikipedia / Wikidata ──(Kotlin の WikiClient が API で取得)──> Wikitext パーサ ──> library.json.gz
        │                                                                          │
        │                         (アプリ版) 起動時に読み、7 日以上古ければ自動更新   │
        │                         (Web 版) --export で JSON にし、R2 に置く ◀───────┘
        ▼
LibraryService: 能力値・得意な馬場と距離を計算 ──> /api/horses などで画面へ
```

## 注意点

- **能力値は Wikipedia の記事に書かれた実績から計算した参考値** です。記事の書き方 (勝ち鞍の書き漏れなど) に影響されます
- **サンプル出馬表のオッズは実際の市場を再現していません** (オッズの逆数の和が 1.714 で、控除率に直すと 42%)
- 今週の出馬表とオッズは、JRA 公式サイトから 1 分に 1 件ずつ自動で取り込みます (仕組みは [実際のレースの予想](/learn/live))。公開 API ではないため、利用規約の上ではグレーな使い方です。ページそのものは保存せず、馬名・オッズなどの事実のデータだけを保存しています
- 地方競馬 (NAR) は、公式サイトが自動取得を禁止している (robots.txt) ため対象外です
- 写真を使うときは、各写真に表示している作者名とライセンスを守ってください

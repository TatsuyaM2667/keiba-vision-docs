## 確率・統計

| 用語 | 意味 |
|---|---|
| 確率変数 | 結果によって値が決まる数。例: その日の馬の出来 |
| 期待値 $E[X]$ | 何度もくり返したときの平均 |
| 分散 $V[X]$ | 平均からのずれの 2 乗の平均。ばらつきの大きさ |
| 標準偏差 $\sigma$ | 分散の平方根。単位が元の値と同じ |
| 独立 | 一方の結果が他方に影響しないこと。独立なら分散は足し算 |
| 一様分布 | 範囲内のどの値も同じ確率で出る分布 |
| 正規分布 | 左右対称の釣り鐘型の分布 |
| 標準正規分布 / Φ | 平均 0・標準偏差 1 の正規分布 / その累積分布関数 |
| Irwin–Hall 分布 | 一様乱数 $n$ 個の和の分布 |
| Gumbel 分布 | 最大値の分布。揺らぎに使うと 1 着の確率が softmax になる |
| 中心極限定理 | 独立な乱数をたくさん足すと正規分布に近づく、という定理 |
| 大数の法則 | 回数を増やすと平均が真の値に近づく、という法則 |
| モンテカルロ法 | 乱数で何度も試して確率や平均を求める方法 |
| 推定量 / 不偏 | データから計算する推定値の式 / その期待値が真の値に一致すること |
| 標準誤差 | 推定値の標準偏差。$\sqrt{p(1-p)/N}$ |
| 信頼区間 | 真の値が入ると考えられる範囲。95% なら ±1.96 標準誤差 |
| 最尤推定 | 実際のデータが最も起こりやすくなるようにパラメータを決める方法 |
| Brier スコア / 対数損失 | 確率予想の良さを測る指標 (どちらも小さいほど良い) |
| softmax | 点数を、合計 1 の確率に変える関数 $e^{\beta S_i}/\sum e^{\beta S_j}$ |
| Thurstone モデル | 出来 = 平均 + 正規分布の揺らぎ、で順位が決まるモデル |
| Plackett–Luce モデル | 出来 = 平均 + Gumbel の揺らぎ。1 着の確率が softmax になる |
| Harville の公式 | 1 着の確率から 2 着・3 着の確率を計算する式 |
| ケリー基準 | 資金の増え方が最大になる賭けの割合 $(pO - 1)/(O - 1)$ |
| パーセンタイル | 全体の中で下から何割の位置にいるか |

## 数学一般

| 用語 | 意味 |
|---|---|
| clamp (クリップ) | 値を上限・下限の範囲に収める操作 |
| 加重平均 | 重みを掛けて合計する平均 (重みの合計を 1 にする) |
| 凹関数 | 傾きがだんだん小さくなる関数 (例: $\sqrt{x}$、$\log x$) |
| 限界効用の逓減 | 量が増えるほど 1 単位の価値が下がること |
| 単調 | 常に増える (または常に減る) こと |
| $C^1$ 級 | 値も傾き (微分) もつながっていること |
| 線形補間 (lerp) | 2 点を直線で結んで途中の値を求めること |
| 指数関数的な減衰 | 「自分の大きさに比例して減る」量の振る舞い。$e^{-\lambda t}$ |
| 半減期 / 時定数 | 半分になるまでの時間 / $e^{-1}$ (約 37%) になるまでの時間 |
| パラメータ表示 | 曲線上の点を 1 つの変数 (距離 $s$ など) で表すこと |
| 単位ベクトル / 法線 | 長さ 1 のベクトル / 曲線に垂直な向き |
| 鏡映 | 鏡に映したように反転する変換 |
| atan2 | 点 $(x, y)$ の角度を 4 象限すべてで正しく返す関数 |
| XOR (⊕) | ビットごとに、違えば 1・同じなら 0 |
| ハッシュ | データから決まった計算で作る「指紋」の数 |

## 競馬

| 用語 | 意味 |
|---|---|
| 脚質 | 逃げ (先頭) / 先行 (前方) / 差し (中団から) / 追込 (後方から) |
| ペース | 前半の速さ。ハイペースは前の馬が疲れて後ろが有利 |
| スピード指数 | 走破タイムを数値化した能力の目安 |
| 枠 / 馬番 | スタート位置のグループ (1〜8) / 馬ごとの番号 |
| 馬身 | 馬 1 頭分の長さ (約 2.4m)。着差の単位 |
| ハナ・アタマ・クビ | 1 馬身より小さい着差 (鼻・頭・首の差) |
| ハロン棒 | ゴールまでの残り距離を示す柱。1 ハロン = 約 200m |
| 内ラチ / 外ラチ | コースの内側 / 外側の柵 |
| 控除率 | 賭け金の総額から主催者が差し引く割合 (JRA 単勝 20%) |
| パリミュチュエル方式 | 控除した残りを当たった人で分ける方式。オッズは賭け金の割合で決まる |
| 単勝 / 馬連 / 馬単 / 3 連複 / 3 連単 | 1 着 / 1・2 着の 2 頭 (順不同) / 1・2 着の順 / 1〜3 着の 3 頭 (順不同) / 1〜3 着の順 |
| クロス / 血量 / 近交係数 | 同じ祖先が両親の血統に出ること / その祖先の割合 / 同じ遺伝子を 2 つ持つ確率 |
| 含水率 | 馬場の土に含まれる水の割合。良・稍重・重・不良はこれで決まる |

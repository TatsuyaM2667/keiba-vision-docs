## スタジアム曲線

実際の競馬場の形は場ごとに違いますが、3D では陸上トラックと同じ **スタジアム曲線** で近似しています。

- 直線の長さ $S$ … 各競馬場の「最後の直線」の値 (東京 525.9m など)
- コーナーの半径 $R = 110 + 0.1\,S$ … 直線が長い競馬場ほど少し大きく
- 1 周の長さ $L = 2S + 2\pi R$

東京なら $R = 110 + 52.59 = 162.59$m、$L = 1051.8 + 1021.6 = 2073.4$m です (実際の東京の芝コースは 1 周 2,083m なので、近い値になっています)。

## 距離でのパラメータ表示

コース上の点を「内ラチ沿いにスタート地点から $s$ メートル進んだ点」で指定します。内ラチから外へ $o$ メートル離れた点の座標 $P(s, o) = (x, z)$ は、4 つの区間で式が変わります (上から見て $x$ が右、$z$ が手前)。$r = R + o$ と置きます。

| 区間 | $s$ の範囲 | 位置 $(x, z)$ | 進行方向 $T$ |
|---|---|---|---|
| ホームストレッチ | $0 \le s < S$ | $(-S/2 + s,\ r)$ | $(1, 0)$ |
| 1・2 コーナー | $S \le s < S + \pi R$ | $(S/2 + r\cos p,\ r\sin p)$ | $(\sin p,\ -\cos p)$ |
| 向こう正面 | $S + \pi R \le s < 2S + \pi R$ | $(S/2 - u,\ -r)$ | $(-1, 0)$ |
| 3・4 コーナー | 残り | $(-S/2 + r\cos p,\ r\sin p)$ | $(\sin p,\ -\cos p)$ |

1・2 コーナーでは $p = \pi/2 - (s - S)/R$、3・4 コーナーでは $p = -\pi/2 - (s - 2S - \pi R)/R$、向こう正面では $u = s - (S + \pi R)$ です。$s$ は $L$ で割った余りを使うので、1 周を超える距離 (3,000m など) も同じ式で扱えます。

```js title="src/main/resources/static/js/sim3d.js"
else if (s < S + Math.PI * R) {
  const p = Math.PI / 2 - (s - S) / R;
  x = S / 2 + r * Math.cos(p); z = r * Math.sin(p); dx = Math.sin(p); dz = -Math.cos(p);
}
```

### 半円の式の導き方

中心 $(S/2, 0)$、半径 $r$ の円周上の点は、角度 $p$ を使って $(S/2 + r\cos p,\ r\sin p)$ と書けます。コーナーの入り口 ($s = S$) で真下 (ホームストレッチ側、$p = \pi/2$)、出口 ($s = S + \pi R$) で真上 ($p = -\pi/2$) なので、角度は $\pi/2$ から $-\pi/2$ へ、$s$ に比例して減ります。内ラチ (半径 $R$) に沿って長さ $\ell$ 進むと角度は $\ell / R$ (ラジアン) 変わるので

$$
p = \frac{\pi}{2} - \frac{s - S}{R}
$$

進行方向は位置を $p$ で微分した向きの反対 ($p$ は減っていくため) で、

$$
\frac{d}{dp}(r\cos p,\ r\sin p) = (-r\sin p,\ r\cos p) \;\Longrightarrow\; T = (\sin p,\ -\cos p)
$$

長さは $\sin^2 p + \cos^2 p = 1$ なので、そのまま **単位ベクトル** (長さ 1) です。ホームストレッチの終わり ($p = \pi/2$) では $T = (1, 0)$ となり、直線部分の進行方向とつながります。

:::deepdive 外を回っても損をしない — このモデルの単純化
$s$ は内ラチ (半径 $R$) に沿った距離です。外へ $o$ メートル離れた馬も同じ $s$ で位置が決まるので、コーナーでは半径 $r = R + o$ の円を、内ラチの馬と同じ角度だけ進みます。実際に移動する距離は $r/R$ 倍、つまり **外の馬ほど速く動いている** ことになります。

$o = 10$m、$R = 162.6$m なら 6% 速い計算です。実際の競馬では外を回る馬はその分だけ長い距離を走るので不利 (「距離ロス」) ですが、このモデルでは走破タイムが先に決まっているので、外を回っても損をしません。映像の見た目にだけ影響する単純化です。
:::

## 外向きの法線 — 「差」で求める

スタンドやカメラを「コースの外側」に置くには、外を向いた単位ベクトル (**法線**) $N$ が必要です。アプリは、同じ $s$ で $o$ を 0 と 1 にした 2 点の差を使っています。

```js title="src/main/resources/static/js/sim3d.js"
outward(s) {
  const a = this.at(s, 0), b = this.at(s, 1);
  return new THREE.Vector3(b.x - a.x, 0, b.z - a.z).normalize();
}
```

$$
N(s) = \frac{P(s, 1) - P(s, 0)}{\lVert P(s, 1) - P(s, 0) \rVert}
$$

直線部分では $z$ 方向に 1 ずれるだけ、コーナーでは半径方向に 1 ずれるので、どちらも「コースに垂直で外向き」になります。式を区間ごとに書き分けずに済むのが、この方法の利点です。

## 右回り — 鏡に映す

日本の競馬場は右回り (時計回り) が多く、東京・新潟・中京などは左回りです。上の式は左回りなので、右回りのコースは $x$ 座標の符号を反転して作ります。

```js title="src/main/resources/static/js/sim3d.js"
return { x: x * mirror, z, dx: dx * mirror, dz };
```

$$
(x, z) \;\mapsto\; (-x, z)
$$

これは $z$ 軸を鏡とする **鏡映** です。鏡映は長さを変えないので、$s$ がそのまま距離を表すという性質は保たれます。一方で「時計回り / 反時計回り」は逆になるので、左回りの曲線が右回りの曲線になります。

## スタートとゴールの位置

ゴールはホームストレッチの 85% の位置 $G = 0.85\,S$ に置き、スタートはそこから距離 $D$ だけ戻った点です。

$$
s_\text{start} = (G - D) \bmod L
$$

東京 2,400m なら $G = 447.0$、$(447.0 - 2400) \bmod 2073.4 = 120.4$。スタート地点はホームストレッチ上、ゴール板の 326.6m 手前になり、1 周と少しを走ることになります (実際の東京芝 2,400m もスタンド前の発走で、1 周と少しです)。

ばんえい (帯広) は直線コースなので、コーナーを持たない $(-S/2 + s,\ o)$ だけを使います。

## 3D の向き — atan2

3D の物体 (馬・発馬機・ゴール線) を、ある水平ベクトル $v = (v_x, v_z)$ の向きに回すには、$y$ 軸 (上下) まわりの回転角 $\theta$ を求めます。$y$ 軸まわりに $\theta$ 回すと、

$$
(1, 0, 0) \mapsto (\cos\theta,\ 0,\ -\sin\theta), \qquad (0, 0, 1) \mapsto (\sin\theta,\ 0,\ \cos\theta)
$$

になります (three.js の右手系)。

- 馬は前方が $+z$ なので、$(\sin\theta, \cos\theta) = (d_x, d_z)$ を解いて $\theta = \operatorname{atan2}(d_x, d_z)$
- 発馬機やゴール線は長い方が $+x$ なので、$(\cos\theta, -\sin\theta) = (v_x, v_z)$ を解いて $\theta = \operatorname{atan2}(-v_z, v_x)$

```js title="src/main/resources/static/js/sim3d.js"
const alongX = v => Math.atan2(-v.z, v.x);
// ...
h.root.rotation.y = Math.atan2(p.dx, p.dz);
```

$\operatorname{atan2}(y, x)$ は「点 $(x, y)$ の角度」を $-\pi$〜$\pi$ で返す関数で、$\arctan(y/x)$ と違って $x = 0$ でも使え、4 つの象限を正しく区別できます。

:::recap
- コースは直線 2 本 + 半円 2 つ。$R = 110 + 0.1S$、$L = 2S + 2\pi R$
- 位置は内ラチ沿いの距離 $s$ と、内ラチからの距離 $o$ で決まる
- 半円の進行方向 $(\sin p, -\cos p)$ は、位置を微分して得られる単位ベクトル
- 外向きの法線は「$o = 1$ と $o = 0$ の差」で、区間を問わず求まる
- 右回りは $x$ の符号を反転 (鏡映) するだけ
- 回転角は $\operatorname{atan2}$。このモデルでは外を回る距離ロスはない
:::

:::challenge コーナーのどこ？
東京 ($S = 525.9$、$R = 162.59$) で $s = 800$ の点は、どの区間の何度の位置ですか。
---答え---
$S = 525.9 \le 800 < S + \pi R = 1036.7$ なので 1・2 コーナー。$p = \pi/2 - (800 - 525.9)/162.59 = 1.5708 - 1.6858 = -0.115$ ラジアン (約 −6.6°)。コーナーのちょうど真ん中 ($p = 0$) を少し過ぎた所です。
:::
